# Plan: One and Only Entertainment — Luxury Landing Page

## Overview
- Static single-page, mobile-first, fully responsive
- Stack: HTML5 + Tailwind CSS (CDN) + vanilla JS
- Theme: luxury dark — jet black, metallic gold, silver, crimson accents (NO pink/purple)

## Files
- `index.html` — structure + all sections
- `assets/css/main.css` — theme tokens, gold gradient, animations
- `assets/js/main.js` — menu, reveal-on-scroll, form validation

## Sections
1. Header/Nav — gold logo, menu, "Call Richie" CTA
2. Hero — "WHERE ENTERTAINMENT MEETS CLASS" + dual CTA
3. Featured Packages — 3 packages, "Starting at $250"
4. Special Discounts — up to 25% OFF (crimson badges)
5. Meet The Entertainers — diverse cards + "Request" buttons
6. Lead Form — quote request fields
7. Footer — legal disclaimer, links, contact

## Defaults (swappable)
- Phone: placeholder `(555) 123-4567` / `tel:+15551234567`
- Entertainer images: monogram placeholders (swap real licensed photos later)
- Form: front-end only (no backend)
- Locations: "Nationwide VIP Service" / "Top Tier Event Destinations"
